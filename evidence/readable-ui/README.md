# 短螢幕、字級、對比與操作範圍

## U14 短視窗
- 小螢幕（寬850以下或高700以下）及放大文字使用獨立可捲動資訊面板，固定關閉鈕；背景工具不接收點擊。離開面板回到場景。
- Chrome 的視窗工具有1.1倍率差，因此以429×660及660×429工具設定，實際DOM核得390×600及600×390 CSS像素；不是只按工具設定值宣稱。
- 390×600面板實測374×584；600×390為584×374。管理鈕可由Tab或捲動到達，橫向實際升至2級、直向進入四格搬移再取消。對應圖片與完整AX均保留。
- 工具收合後仍保留營造預覽、費用、禁止原因與取消鈕；build-preview.png為鍵盤移格真實預覽。橫向減少固定抬頭占用，600x390-town.png仍保有可觀察場景。

## U15 可放大文字
- 原有px字級轉rem；核心標籤至少.75rem（預設16px時12px），正文.875rem（14px）。「營造與工具→文字」可切100%、150%、200%。
- 保留使用者瀏覽器較大預設字級：本機基準root20px、正文17.5px，200%為root40px、正文35px，確實兩倍。200-percent-metrics.json顯示scrollWidth=clientWidth=370，管理鈕換行且能聚焦。圖片保留可見關閉與操作。
- 字級設定為本次頁面操作，不新增存檔欄位；重新載入回到瀏覽器原有預設。

## U16 對比
- 使用不透明紙底#f7f4e7，降低對移動畫面/日夜背景的依賴。由實際DOM computedStyle回讀色彩與不透明祖先底色，再按sRGB相對亮度公式計算。
- 採樣包含可見文字，排除純裝飾場景題字及停用按鈕；不以大字降低4.5:1門檻。對話框背後的既有UI文字也可能列入，是較保守的重複採樣。
- day: 26筆，最低5.64:1，最低實測字級15px。
- night: 26筆，最低5.64:1，最低實測字級15px。
- help: 58筆，最低5.64:1，最低實測字級15px。
- blueprint: 177筆，最低4.79:1，最低實測字級15px。
- card: 33筆，最低6.13:1，最低實測字級17.5px。

## U17 常用控制
- 問號、縮放、暫停、倍率皆CSS min-width/min-height44px，保留6px以上間距。touch-targets.json核得中心點命中自身，矩形約43.991px為當前Chrome縮放下的小數捨入。
- 實際操作問號開說明、倍率1×→2×，放大與縮小照片保留；全程暫停維持「繼續」，時鐘02:36不變，沒有誤觸相鄰的播放或倍率。control-actions.json保留前後讀回。
- 為Chrome手機尺寸及瀏覽器點擊驗證，非實體手機人工觸控或真人讀屏測試。
