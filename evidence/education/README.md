# C21 書院教育驗收

## 契約與實作
- 落成未受損書院依住家步道24步起涵蓋居民；每級8席，升級加4步，欠款按公共服務效率縮減容量。病假、無家、無路與範圍外不受教。
- 優先低學力；交疊書院以可重分配名額分配，不重複加點。每360遊戲秒10點，最高100，滿級釋出名額。
- education小數保存；舊檔預設0，讀取不獲補發。自由營造不累積、不套用產能加成。
- 真到場健康工匠的平均學力加成0–20％，直接作用於同一原料加工進度。缺工、缺料及受損仍不能生產。
