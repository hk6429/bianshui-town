# C18 衛生與 C04 欠款驗收

2026-09-16，本機開發版；沒有部署。根代理操作驗收，不是獨立專家複評或真人玩家驗收。

## 實作與規則

- 每日人口1份/人、每件實際製成商品2份。building.waste/pendingWaste保存負荷；只有完成生產才加待結算量，清運容量與實際路程限制每日抵消量。
- 一格清運院每日12份×tier，四格48份×tier；範圍24+4×(tier-1)。有限容量的殘餘流分配讓交疊清運院互相讓出處理量，不會有能清而未清的單一覆蓋住宅。
- 髒污降低衛生分數與住宅需求；住家/工作地負荷每日至多使健康降12，乾淨後每日回5，界限0–100。並未宣稱C20醫療或C25幸福度完成。
- 欠款服務效率依連續欠款日為75%、50%、25%，下限25%；金庫非負即100%。水井實際可分配容量與清運實際處理量共同受限。付費新建仍受affordable限制，拆除、政策、自由營造退出路徑保留。
- 多日財政結算只計真正陷入欠款後的連續天數，非把前面金庫有餘額的日子也算進去。
- 存檔v9新增可選building.waste/pendingWaste、person.health、city.sanitationDay。舊存檔從當天起算；非法數值與未來日拒絕。模式切換不追算；sandbox不累積新負荷。正常tick跨日正常結算；外部推進/過舊游標最多回放7日，防止無界迴圈。

## Chrome 證據

- sanitation-harness只執行正式財政/衛生模組逐日結算，不推進其他居民生活排程；未把它當完整城鎮長期遊玩平衡驗證。
- 未接清運道路：第2日髒污4、健康99；第3日髒污8、健康98（unserved.txt）。接路結算後髒污0、健康100（cleaned.txt）。
- 三日欠款：金庫-10/-20/-30，服務75/50/25%，清運9/6/3；第三日供水3/4，髒污1（debt-stages.txt）。
- 調稅20%後五日每日淨收6文，金庫0、欠款日0，供水4/4、清運12、髒污0（debt-recovered.txt）。
- 實際三維遊戲載入同一隔離存檔，清運造型／資訊卡、衛生與健康總覽、公共營造入口皆確認：3d-yard、3d-budget、3d-public-works。
