# C22 作坊污染與住宅混置驗收

## 實作契約
- 真實完成成品才排放，陶器18/木器8/布匹14；三格內按距離衰減，四格作坊均分每件排放至實際四格源頭。
- city.pollution最多143格，各格0–100，不接受重複格、越界及非有限值；舊存檔缺省零污染，保存小數、不補算離線時間。
- 每90遊戲秒減半。污染保留於土地，搬移或拆除源頭不瞬間清除；缺工缺料、庫滿及受損不新增排放。
- 住宅居住環境=100減占地平均污染；全城按住戶權重（空屋1）平均，住宅需求最多扣30，新入住/安置優先低污染合格住宅。自由營造凍結數值、不影響需求。
- 與衛生髒污分開；本項以住宅需求表現環境取捨，不重複扣健康。數值是遊戲設計，非歷史測量。
