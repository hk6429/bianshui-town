# 玩家道路因果與通行容量 — C13/C14

基準7337a0a，C13/C14聚焦驗收通過；最終四領域複評與部署尚未完成。

## 規則
- 經營模式保留街坊門前步道，跨街坊不再自動BFS接路。新城提供(2,2)一格小路，接公共貨棧支線(10,8)→(16,8)；起始引道每日維護1文。自由營造維持自動接路，切換模式立即重建。
- 新住戶需要住宅接通河岸。工作配對依實際連通；送貨跳過不可達目的地。斷路後，人物不跨遠處缺口、不把空路徑當抵達；牛車/腳夫實際到門口才卸貨，載貨推車保留商品並等待可達商鋪。
- roadAnchor僅取1.01單位內道路；roadReachable按道路Set及revision快取連通分量，避免失聯貨車每tick反覆全圖BFS。
- 大路為同向雙行人列；同基礎速度下可分流並繞車，小路遇車讓行。遇車時大路兩列仍保留不同偏移，不疊在同一列。每格20/45文；小路升大路補25文，不改建築占地。
- 文人無法跨隔離瞬移或在未到達景點時收錄作品；重鋪後恢復走訪。原作品內容未修改。
