## 驗收契約與證據

- 窯坊及周圍2.5格內已落成非公用設施提高風險，最高30%。巡守依實際道路距離24+4×(tier-1)及有限容量分配，一格8×tier、四格32×tier，乘欠款服務效率。優先高風險建築。
- 固定日序/建築ID抽樣，前兩日免事件，一日最多一處預警。注入同一draw=0可重現事件；有巡守損害12、無巡守60，整修24/120秒。正常固定抽樣連續120日兩城（其一反覆存讀）事件紀錄一致，確有事件而非全部跳過。
- 預警30秒才受損，期間建巡守會在受損時重算覆蓋；可付20文取消。受損會真正停止tickProduction與shopIsOpen；保留建築、居民/住所、全部貨物，住宅健康只減2或10。
- 整修倒數免費完成；金庫不足不能付費修復，但不妨礙免費復原。付費修復依損害×占地，經editTown原子流程儲存。sandbox暫停事件，可免費排除/修復。
- fireDay以及fireWarningAt/fireDamage/fireRepairAt為v9可選白名單；受損/修復時間須成對，預警與受損不得同時存在，未來檢查日拒絕。舊檔從當天起算。
