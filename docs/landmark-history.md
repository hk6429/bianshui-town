# 文學地標外型與歷史界線

## 岳陽樓

目前遊戲使用四格縮尺模型，參照現存清代形制，不是宋代原樓精確復原，也不是測繪模型。范仲淹的文章與玩家所見建築外型屬不同年代，任務說明已揭露。

依據岳陽市官方文保說明與官方照片，呈現三層木構、黃瓦、上翹飛簷、盔頂曲面、朱木門窗、二層迴廊與斗栱意象。五級升級增加香具、圍欄、樹景與文學碑，保留三層主體。省略不可由照片精確證明的尺寸、構件數與彩繪細節；各官方舊文高度數值不同，因此不標示精確比例。

## 其他九座

開封府為宋代衙署題材與後世包公公案的遊戲改編，不把陳世美故事當包拯可考實錄；其餘亭、池、文舟、技藝坊、燈市、望月臺為對應作品的文學意象，並非原址測繪重建。赤壁文舟、愛蓮池、溪亭荷塘的水面在四格內，是內置景觀，不代表可通航的城市河道。

圖鑑／任務提供原文節錄、作者、來源連結與改編提示。操作小場景不會挖掉玩家真實城市、消耗鎮庫或憑空生成交易。
