# 活著的汴水小鎮：第二版

## 依據與轉譯

參考故宮博物院 [張擇端《清明上河圖》卷藏品介紹](https://www.dpm.org.cn/collection/paint/228226.html)。官方介紹的構圖重點為市郊、以虹橋為中心的汴河水運，以及城內街市；特別描述船隻放倒桅杆穿橋、人群圍觀與大小店鋪。

本版將這些重點轉成可觀察的互動：城門來客穿過木拱橋，走進街市；漕船收桅穿橋、靠岸卸貨；腳夫把貨物搬入貨棧，再由牛車運往商鋪。

牛車、挑擔、院落細節以宋代市井意象製作；不是逐一復原畫中每個人物與物件。夜景、居民時間表、動物活動與程序音景屬遊戲延伸，不能當作畫作本身描繪的事件。

## 動態契約

| 系統 | 實際行為 | 驗證 |
|---|---|---|
| 漕船 | 航入、收桅過橋、靠岸、等候卸完、離港、下一航次 | 測試桅杆狀態與航次 |
| 腳夫 | 船邊領貨，每次一件，走回貨棧入庫 | 貨物移交與庫存 |
| 牛車 | 從貨棧裝最多三件，送到低庫存商鋪，空車返回 | 商鋪實際收到貨物 |
| 來客 | 城門出發、過橋、逛店、橋上看船、返回城門 | 道路路徑與夜間散場 |
| 居民 | 工作、採買、返家；相遇可停步交談四秒 | 交談結束恢復日程 |
| 生活細節 | 門前工作、工匠手勢、晾衣擺動、營業時炊煙 | 實際場景截圖 |
| 河岸生機 | 釣魚、洗衣、犬、鴨、飛鳥 | 程式化環境動畫 |
| 音景 | 水風底音、日鳥／夜蟲、木作與車輪節奏 | 主動啟用、暫停靜音、關閉狀態 |
| 見聞面板 | 真實事件與貨量，一鍵聚焦虹橋／碼頭／街坊 | 穩定按鈕與點擊測試 |

## 貨物守恆

累計進口 = 船上貨物 + 腳夫手中 + 貨棧庫存 + 牛車運送中 + 商鋪庫存 + 已售出。

`cargoBalance()` 計算此關係；多航次測試驗證沒有憑空增加或減少。工作作坊的既有手推車未納入這條進口帳，不會暗中改變河運庫存。

## 舊檔與保護

- 沿用 `bianshui-town-v1` 儲存鍵，內部格式升至 version 2。
- version 1 的居民、街坊與時間保留，新增生活系統以初始狀態補入。
- 新示範鎮 26 間建築、26 位居民、12 處街坊；不會用新示範鎮覆蓋舊存檔。
- 公共河岸道路、橋面及碼頭加入路網；建築內部仍不可通行。
- 重設需沿用原本的確認視窗；環境音預設關閉。

## 實作取捨

- 環境音使用 Web Audio 合成，沒有下載音效或自動播放。
- 合併草地細節網格，減少增加人流後的繪製負擔。
- 船桅、人物、晾衣、炊煙、動物均由模擬時間驅動，暫停時保持靜止。
- 見聞按鈕在更新時保留節點；只更新文字、數字與事件，避免點擊途中被替換。
- 相遇、車流沒有完整物理碰撞；此版目標為輕鬆觀察的小鎮生活。
