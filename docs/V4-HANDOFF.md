# 第四版：雨巷與物產

## 本波契約
補驗街頭跳轉，完成雨天／撐傘／避雨、共享院落與側門／晾曬、多品項原料到成品的實際物流。基準提交：8cbe1bc。

## 實作進度
- 街頭按鈕使用固定 DOM，支援回看上一場地點；抽出 focusAt 並測試鏡頭中心／退出跟隨。
- 天候可自然循環或手動切換。雨中取消聚會、部分居民避雨、其他行人撐傘；雨停恢復日程。
- 2–3 格街坊縮入建築量體，在中間留共享院落、側門、晾曬；內部不產生道路。
- 泥料→陶器、木材→木器、纖維→布匹；每件貨記錄航次、移交位置、製作作坊與售出。牛車供料、推車送成品，工匠必須在場才能加工。
- 補貨依最後補給時間輪流分配，修正織坊原料被其他作坊餓死。
- v1–v3 的既有貨物遷移為日用雜貨；v4 保留新物流與天候。
