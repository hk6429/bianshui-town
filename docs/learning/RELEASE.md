| 學習需求 | 實作 | 證據 |

## 驗證結果

- 全套單元測試：405／405 通過，含 SQLite API 實際學習資料保存讀回、授權與存檔驗證。
- 十關瀏覽器：閱讀、30個場景活動、解鎖、作品重載、五級模型與390px檢查通過。
- 學生流程：提示不丟草稿、錯答保留、證據與理由、兩版作品、回憶／遷移、SVG下載、重載、390px通過。
- 教師流程：指定任務、準備場景、原城市隔離、作業匯出匯入、評語返回學生版本、390px通過。
- 正式發布的部署識別與讀回結果另見 HANDOFF.md 及 evidence/learning/production-*。

## 適用範圍與限制

- 三種閱讀支援可自由切換，不能當作年級或能力測驗。
- 選擇符合題意不代表理由完整。開放文字等待人工判讀，不用關鍵字自動給理解分數。
- 課堂15–20分鐘是設計目標，尚未做真實國小／國中學生試玩或學力成效研究。
- 教師看板以檔案交換、本機彙整；不是即時全班同步，也不是防作弊正式成績系統。
- 一般城市的學習紀錄沿用 Google／Turso 雲端存檔；指定課堂場景採獨立本機檔，保護原城。
- 已做隔離瀏覽器與手機尺寸檢查，尚非跨實體裝置或真人驗收。
- 圖像為教學示意，段落是選讀而非全文；保留全文來源與建築、故事改編界線。
