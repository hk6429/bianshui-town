# 學習優化執行契約

原始目標：依學習優化提案實作並部署；不可只完成示範關就宣告全部完成。

## 里程碑

1. 學習資料與存檔：十關學習目標、三種閱讀支援、證據卡、提示／嘗試紀錄、短箋版本、預測與反思、隔次複習；兼容舊檔且通過雲端 schema。
2. 學生介面：一個當前目標、三種支援可切換、逐句朗讀與關鍵詞注音、證據選句與理由、四層提示、改寫與作品卡；閱讀支援不是年級限制。
3. 教室場景：預備道路和前置設施、任務期間暫停經營干擾、保護原城；教師可指定關卡／支援，15–20 分鐘為待試玩調整的目標。開封府完整示範後延伸十關。
4. 教師看板：指定任務、全班常見卡點、個人證據／提示／修改紀錄；明確區分完成、提示協助、獨立解釋與遷移；人工判讀開放題。不用速度／建築等級排名。採可匯出匯入的學生學習紀錄供教師彙整，清楚說明非即時全班同步；保留後續即時班級服務擴充點。
5. 驗證與部署：聚焦測試、存檔安全、十關內容、桌面／手機關鍵操作、雲端保存、新舊檔、部署兩站與讀回。記錄未實測的教育成效、跨實體裝置限制。

## 學習循環

讀懂 → 找證據 → 做決定 → 說理由 → 換情境再試。每關須能觀察到證據與理由，不能用選擇題答對冒充論述品質。

## 驗證契約

- 三支援模式均可切換，不清除內容；朗讀失敗時提供文字回退。
- 錯誤、提示、成功與修改都保留；不扣建築或強制每天登入。
- 原文與遊戲改編分明，現有地標史料界線保留。
- 複習使用現實日期，不靠加速遊戲時間觸發；可跳過。
- 開放題記為待判讀，教師評語與判定可追溯到提交版本。
- 任務場景不得覆蓋既有城市而不留復原；重複進入不可領取城鎮資源獎勵。
- 匯入學習紀錄需版本、大小、欄位與跨欄位驗證，文字轉義，不執行內容。
- 十關均有目標、白話支援、語詞提示與遷移題，避免只換關名的空殼。

根代理直接實作資料層及學生閱讀流程。完成後另寫 HANDOFF.md，下一波接課堂場景／教師看板；不重複整套驗收。
