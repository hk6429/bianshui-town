# 八角優化執行契約

使用者要求派遊戲化專家，把八項評分朝9分優化。9分是設計目標，不得用新增功能數或修改評分規則宣稱已實測達標。

## 分工

- adventure_design：十關使命、線索、資源取捨、居民後果、可重玩與收藏；獨立資料層及測試。
- adventure_ui：先情境後說明的漸進式介面、可見回饋、手機操作。
- root：小隊互補合作、權限與版本保存；主介面／存檔整合；測試與發布。
- 受代理執行緒上限限制，合作模組由root處理。最終使用獨立審查代理依證據重評。

## 八項觀察指標

1. 使命：進入即遇到有姓名／需要的角色，知道自己的行動幫助誰。
2. 成就：閱讀證據、訪查、作品有可見里程碑；獎勵不假冒理解認證。
3. 創意：至少兩種合理路徑、可重配資源、記錄理由及修正。
4. 擁有：收藏／決策履歷跟隨城市存檔，重玩不清除成果。
5. 合作：隊員有互補角色、個別證據與理由、回應隊友、共同結論；無法代寫隊友或看他隊。
6. 稀缺：有限演練資源對選擇產生真取捨；沒有現實倒數、付費或強制等待。
7. 好奇：線索逐步揭露、不同路徑後果與下一輪問題；不靠賭博獎勵。
8. 避免損失：有需要守護的居民與可逆失誤修復；不扣學生既有城市／作品、不以不登入威脅損失。

## 邊界

原城與舊檔兼容、一般雲端保存與班級作業權限不可退步。所有史料與遊戲改編分清。真實學生參與、回訪與學習成效仍需試玩資料。先做一個完整功能里程碑，保存handoff後交付獨立審查，不派長駐跨wave代理。
