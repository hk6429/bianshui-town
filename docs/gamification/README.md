# 文學冒險與探究小隊

## 學生如何開始

選任一文學關卡，先聽三位居民的線索，決定如何安排演練專用的時間和援助。居民會回應安排的優點與未解需要，再由你選擇後續守護對象。這些內容是教學情境推演，不是史料。

想法可以先口述；不以關鍵字給理解分數。回到原文完成三段證據閱讀並保留作品後，可領本篇紀念收藏。重玩能比較另一安排，收藏不重複領取，也不扣原城資源。歷程只保留最近12次決策，超出會移除最早一筆。

## 老師如何安排合作

「我的班級與作業」選既有任務 →「文學探究小隊」→安排2–4位已加入班級的學生。依名單分配原文尋訪、不同觀點、推論整理、證據檢查角色。

每人提交自己的原文線索和理由，再回應至少一位隊友。全員參與後才能保存共同結論。老師可查看每個版本的貢獻快照；學生只看自己隊伍，不能代寫他人內容。背景同步提示新線索，按更新後閱讀；未送出的草稿保留。

共同結論是小隊的學習作品，不代表全員已理解或一致同意；教師仍須查看理由、追問與分工是否公平。無帳號學生仍可使用單人冒險並以口述／紙本合作。

## 評分界線

目標是八項朝9分設計，但新增功能不等於學生動機或學習成效已達9。INDEPENDENT-REVIEW.md保留獨立初評、已修問題與仍待試玩的差距；不以倒數、強制登入或不可逆懲罰追求稀缺與損失避免高分。

## 岳陽樓跨輪探究

第一輪先訪查林安、周禾、許木（三位均為教學虛構），完成主要安排與後續安排。在冒險歷程選「換個安排再演練」，第二輪會依最近前輪的四種安排之一，呈現具名居民記憶與新的需要。展開「查看前輪記憶與新線索」，選一句原文、填寫修正理由，按「儲存這次修正」。選文只記錄學生引用，不自動判定理解或理由正確。

修正稿保存於城市存檔，只保留當輪最新版；重新演練清除，可先匯出城市存檔留存。最近前輪若尚未完成後續安排，不會借用更早輪次的故事。其他九關本輪未加入跨輪劇情。
