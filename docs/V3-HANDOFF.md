# 第三版：有故事的市井（0.3.0）

## 本波契約與結果
依 2026-09-15 的第三版構想，完成優先三項：居民跟隨、街頭小事件、人車避讓。

- `stories.js`：說書、攤前招呼、茶坊熟客三種聚會。最多四位既有居民沿道路到不同位置集合，停留後散場；夜間中止並恢復原行程。
- `traffic.js`：同向保持距離、對向靠右、牛車／推車優先、橋頭擁擠減速。靜止者不會顯示讓車狀態。
- 居民卡顯示當下目的與每日最多 12 筆真實記事；屋舍中的住戶及工作者姓名可點選。
- 跟隨鏡頭保留角度與縮放，居民入屋後停留在屋舍。拖曳、建造、Esc、重設視角或停止按鈕可退出。
- 第一、二版存檔自動遷移為第三版，保留屋舍、居民、貨物及舊進度。

## 驗證證據
- `evidence/v3/unit-tests.txt`：23 項 Node 測試通過，包括舊功能回歸、事件聚散／夜間返家、記事換日、存檔遷移、鏡頭追蹤／入屋、讓車／同向間距。
- 長時間模擬 1,200 秒：三種事件全部出現、8 場完成；貨物匯入 72 件、核算仍為 72 件。
- `evidence/v3/build.txt`：Vite build 成功，保留既有主程式 >500 kB 提醒。
- CUA 操作既有 Chrome：示範小鎮載入；點選民居、住戶姓名、跟隨按鈕，鏡頭移到居民處且顯示跟隨狀態；Esc 成功清除跟隨與資訊卡。
- `evidence/v3/01-follow.png`：實際 Chrome 的跟隨畫面。
- `evidence/v3/02-mobile.png`：390×844 視窗的市井面板、標題、工具列畫面；標題換行已修正。
- Chrome 見聞讀回：說書開始／結束、攤前聚會開始／結束、茶坊集合後於夜間取消；日誌查詢未見執行錯誤。
- 實測發現街頭觀看按鈕因 innerHTML 序列化空屬性而反覆重建，已改為快取輸入內容。完整的事件跳轉操作仍未取得可靠 UI 回讀，瀏覽器操作工具曾多次逾時；不宣稱這項端到端測試已通過。

## 限制與後續
- 避讓是局部規則及視覺側移，尚非完整物理碰撞；路口、停靠點與進出屋舍可能短暫重疊，尚未加入攤位排隊。
- 街頭聚會使用同一位招呼人物與「聚」招牌，沒有新增語音說書或孩童角色。
- 雨天、畫卷巡遊、進階院落、多品項生產及存檔匯出／匯入留待後續版本。
- 本次是代理透過 CUA 操作 Chrome 的驗證，不等於使用者親自驗收；手機尺寸為桌面瀏覽器模擬，尚未實機觸控驗證。
- 本機 Vite 預覽，沒有部署公開遊戲網址。
