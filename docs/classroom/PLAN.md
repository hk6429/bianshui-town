# 課堂第二階段契約

使用者選擇1+2+3：課堂試玩包、學生引導與手機介面、即時班級派課交作業。

- 沿用 Google 登入、Cloudflare、Turso。老師建立班級即為該班管理者；學生以班級碼加入。沒有 Google 帳號仍可用原有本機學習與檔案交作業。
- 班級有界：每人10個自建班、每班60人、每班20份任務；老師可關閉加入與收件。
- 學生只讀自己的提交與回饋；老師只讀自己班級。提交只含指定關卡學習資料，不含城市或其他關卡。
- 作業以版本保存，重送／跨裝置冲突不覆蓋；回饋綁提交版本。看板開啟時每15秒更新摘要，編輯不受背景更新影響；提供手動更新、最後同步時間與離線提示。
- 課堂網址附作業ID並使用獨立存檔；原城市不受影響。換任務不混用上次作品。
- 新手引導可略過、可重看；手機提供明確下一步與完成清單，不強制遮住閱讀。
- 試玩包涵蓋國小口述／短句、國中證據推論、教師20分鐘流程與觀察紀錄，不宣稱成效或官方課綱對應。
- 驗證：角色隔離、班級碼／收件、大小／欄位、防重送、版本回饋、兩角色自動瀏覽器流程、390px、原城與舊檔兼容、build、雙站部署讀回。
