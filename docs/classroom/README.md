# 班級即時作業與課堂試玩

## 開始

1. 「營造與工具 → 我的班級與作業」，登入現有 Google 帳號。
2. 老師建立班級，分享16碼班級碼。學生以自己的帳號及座號／暱稱加入。
3. 老師發布任務；學生由任務連結進入獨立小鎮。每份作業有自己的本機存檔，不混用先前同關作品。
4. 先儲存作品，再點「交作業／看老師回饋」。只上傳指定關卡，不上傳城市或其他關卡。
5. 老師看證據、理由、修改與常見卡點，對指定提交版本送出回饋；學生帶入評語、修改並提交下一版。
6. 過往提交與評語保留；看板可回看上一版。每個版本的評語送出後不覆蓋。

## 課堂材料

`/classroom-playtest.html` 提供教師20分鐘試玩流程、國小〈活板〉工序任務、國中〈岳陽樓記〉證據推論任務、觀察與回饋表。瀏覽器可列印或另存PDF；空白CSV在 `/classroom-observation.csv`。
低年級可用開封府圖像故事共讀、口述並由教師協助記錄。

## 同步與界線

- 沿用 Cloudflare／Turso／Google，沒有新增 Firebase。資料表見 migration 002。
- 看板開啟時每15秒查詢最新提交摘要，保留正在輸入的評語；可手動重新整理。
- 自動同步摘要不是自動交作業。學生明確按提交才保存雲端版本；離線保留本機作品。
- 每人最多10個自建班、每班60名學生／20份任務、每位學生每份任務30個提交版本。
- 學生只能查看自己的作業；老師只能管理自己建立的班級。教師資格是班級建立者權限，不是學校身分認證。
- 老師可關閉新成員加入與任務收件。班級碼只分享給班級成員。
- 沒有Google帳號仍可玩所有任務，並沿用本機／檔案交作業。
- 換裝置可查看雲端作品與回饋；若本機沒有對應作品，系統提示先閱讀雲端內容再撰寫新稿，不覆蓋現有草稿。
- 開放文字由教師判讀；提示次數、速度與建築等級都不是學力分數。
- 尚未做真實學生學力研究或兩台實體裝置試玩。

## 測試

`node --test tests/classroom-cloud.test.js` 使用真實SQLite與Cloudflare handler驗證角色、版本、關閉收件、CSRF、大小限制。
`tests/classroom-cloud-browser.mjs` 使用兩個隔離瀏覽器、SQLite和相同handler；只有Google身分驗證替換為測試身分，並非真實師生Google登入驗收。
