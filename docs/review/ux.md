# 城市遊戲互動與無障礙評量

基準：`a6a7504`。來源：`index.html`、`src/main.js`、`src/style.css`、`src/scene.js`、`src/simulation.js`、`src/heritage.js` 與 `tests/browser-check.mjs`。

## 評分尺度

0＝未提供；1＝主要流程受阻；2＝有基本實作但多個重大缺口；3＝主要流程可用且有部分替代操作；4＝跨輸入與尺寸完善；5＝有實際跨裝置與輔助技術證據。

| 面向 | 0–5分 | 依據 |
|---|---:|---|
| 城市資訊辨識 | 2 | 有概況、小卡與見聞；缺用途圖例與可選全鎮清單。 |
| 營造操作與預覽 | 2 | 有網格、占地、顏色提示；合建結果未揭露、多指提交風險、缺可讀禁止原因。 |
| 鍵盤與輔助技術 | 1 | 有按鈕及部分快捷鍵；主要建造/選取仍依賴 canvas 指標操作。 |
| 手機與短螢幕 | 2 | 已有多段 media query；短螢幕高度計算、目標大小、確認及取消流程不足。 |
| 焦點與面板 | 2 | 原生 dialog 有基礎模態行為；部分名稱缺失、aside 焦點導引及動態 DOM 焦點保持不足。 |
| 視覺可讀與回饋 | 2 | 有 toast、施工進度；字體偏小、低對比風險、訊息不可回看、無減少動態設定。 |

25 項有界改善以 `ux.json` 為契約；每項含來源證據、嚴重度、修正與驗收。U05/U20 等屬改善缺口，並不宣稱既有產品規格曾承諾。U15 以可讀性目標評量，不宣稱所有小字皆構成規範違反；U16 需依實際合成背景量測才能判定比值。

## 證據限制

本次只做原碼審查，未操作瀏覽器、未使用真人觸控或讀屏，不能稱真人 UI 已驗證。既有 browser-check 測試主要涵蓋滑鼠拖曳及390×844工具列邊界，不涵蓋本表多指、純鍵盤、讀屏、短橫向螢幕、對比量測與文字放大。分數反映原碼成熟度，非實測完成度。

未新增財政、公服模擬、任務、成就或存檔要求；僅審查既有城市互動的理解、可操作性與可及性。

## U07 更正

原先「雅居小樓斜拉四格預覽可建但提交拒絕」不成立，已撤回。`Town.place` 在 spec 大小驗證前將 `residence` 映射成 `mansion`。本次執行 Node 直接呼叫 `Town.place`，輸出 `placed:true,count:1,design:mansion,name:四合雅宅`。U07 已改為「營造預覽未揭露合建結果」：預覽框之外，未同步呈現實際產出的名稱及棟數。這與 U06 的禁止原因及 U20 的既有場景用途圖例分屬不同使用需求。本次額外驗證僅為模型函式執行，仍未操作瀏覽器。
