## 與城市循環的連結

參照城市建造遊戲「觀察 → 選擇 → 建造 → 看到居民結果 → 調整」的抽象循環，將目前的觀察型作品補上自主目標、可完成委託與成果回顧。這不是 SimCity 2000 規格一致性驗證；本輪不審其財政、路網或公共服務計算，也不對原作未查證細節作主張。

25 項詳見 [octalysis.json](octalysis.json)。ID O01–O25 唯一且各有原碼證據、嚴重度、修改方案與可觀察驗收條件。high 代表本次使用者要求的城市循環核心落差；medium 代表可獨立交付的深度功能。共用目標引擎可承接多項，但不能只用一張新增文字卡聲稱全部完成。

## 實作與放行約束

1. 保留自由營造及代表作隨時可讀，不以任務封鎖文化內容。
2. 不引入現實倒數、每日連續簽到、離線懲罰、付費抽取、假居民評價或假人類排行。
3. 任務達成必須依實際資料或玩家動作，不以開面板/等待代替所有任務。
4. 收藏、委託、願景及關係須分別有明確狀態；同一個數字不能假冒多套系統。
5. 驗收至少覆蓋：空鎮引導、另一解法、取消重接、錯過補訪、沙盒切換、重複操作不刷分、階段回顧。
6. 完成實作後逐項填入新的程式證據和測試證據，再另作部署回讀；本檔不預先宣稱已修正。
