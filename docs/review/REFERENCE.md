# 城市經營重整：範圍與參照

## 使用者契約
以《模擬城市 2000》為城市經營設計參照，由四位專家視角 AI 代理評量，整理 100 個獨立且可驗證的修正項，全部實作、驗收後部署。保留宋代市井、文學、人物、五級建築與既有使用者存檔。

四位角色：城市模擬、八角遊戲化、互動與無障礙、工程可靠性。受目前並行上限影響，第四位接續進場；不是省略第四位或由前三位代評。

## 參照來源
- Maxis《SimCity 2000 User's Manual》，Michael Bremer；官方原手冊的公開鏡像：https://classicreload.com/sites/default/files/sim-city-2000-manual.pdf
- Yu-kai Chou 八角架構原文：https://yukaichou.com/gamification-examples/octalysis-gamification-framework/

借鑑城市規劃、住商工需求、預算、基礎服務、資料圖層與居民回饋的因果循環；將題材轉成宋代適用的市政設施。非移植原作程式或美術，非宣稱完整重製所有原作功能。

## 驗收帳本規則
每項包含唯一 ID、問題類型（實際錯誤或新需求缺口）、現有證據、修法、驗收條件、實作檔案、測試與 UI 證據、狀態。跨角色重複項必須合併或換成獨立問題，不以文件或測試數湊 100 項。

只有對應驗收條件已通過才能標記完成。存檔與破壞性操作在隔離測試資料驗證；正式站保留使用者城市。所有 100 項完成後才作最終部署與逐檔讀回。
