# 第二版動態市井交接（v0.2.0）

## 本次變更

- 已加入牛車、挑擔來客、碼頭腳夫、收桅過橋、卸貨與補貨、居民交談、城門街市、晾衣炊煙、工匠與河岸活動、可關閉環境音。
- 公共虹橋與碼頭接入道路；舊版存檔保留建築、居民與時間並補入新系統。
- 新示範鎮為 26 間建築、26 位居民、12 處街坊。
- 見聞面板按鈕保留節點、只更新動態內容；手機選取人物時自動收起見聞，避免資訊卡重疊。

## 測試與證據

- `npm test`：15 / 15 通過，包含原有建造與新生活模擬。
- `tests/journal-browser.mjs`：按鈕更新後仍連接 DOM，三個鏡頭跳轉皆可點選。
- `tests/life-browser.mjs`：0 執行錯誤；音景主動開啟／暫停靜音、收桅、搬貨、送達、交談、牛車檢視、夜間返家／散場、390px 控制項檢查通過。
- 嚴格截圖取樣確認船桅為收起狀態（mast = 0）；腳夫各持 1 件貨；牛車送達 2 件，交談 11 次。
- `evidence/v2/01-bridge.png` 至 `06-mobile.png` 已檢視；`browser-check.json` 保存資料證據。
- 原有 `tests/browser-check.mjs` 回歸通過，0 執行錯誤、四張概念圖全部可載入。新回歸證據存於 `evidence/v2/regression/`，保留前版截圖。
- `npm run build` 通過；主 JS 561.14 kB、gzip 148.33 kB。仍有 Vite 單檔超過 500 kB 的提醒。
- 三維草地細節合併為少量網格，降低增加人流後的繪製負擔。

## 範圍與邊界

- 畫作依據與遊戲轉譯見 `docs/living-town.md`；本版是宋代市井意象的可玩場景，並非逐物歷史復原。
- 所有瀏覽器證據來自獨立 Chromium 自動驗證；未宣稱既有 Chrome 或使用者已完成人工驗收。
- 音景驗證為 AudioContext 狀態、開關與暫停靜音；不是由真人聽感評分。
- 仍採簡化交通，沒有完整碰撞避讓；動物與部分家務是環境動畫。
- 本機預覽維持 http://127.0.0.1:5173/ ，未另行部署公開網站。

## 下一步

由使用者試玩，依實際觀察回饋決定下一個有界里程碑。可針對畫風、街市密度或交通避讓分別調整，保留本次貨物守恆、夜間散場與面板穩定性測試。

# 第一版可玩原型交接

## 已完成

四張開發前概念圖（實際內容使用繁體中文）、Three.js 場景、共享街坊、道路圖、居民日程與尋路、施工、檢視卡、日夜光線、探索相機、示範小鎮、自動存檔。

## 驗證證據

- `npm test`：8 / 8 通過。
- `npm run build`：通過；主 JS 534.80 kB、gzip 138.90 kB，Vite 提醒單一檔案超過 500 kB。
- `tests/browser-check.mjs`：獨立 Chromium 自動化通過。三格拖曳、探索不建造、入住人口、檢視、確認重設、居民移動、返家、夜景、390px 工具列皆有檢查。
- `evidence/browser-check.json`：0 執行錯誤，4 / 4 概念圖載入；範例場景 386 次繪製、69,796 三角形。
- `evidence/01-empty.png` 至 `06-mobile.png`：實際測試瀏覽器截圖。
- 模型屋頂曾因 indexed / non-indexed 幾何與 UV 屬性不一致而合併失敗；已統一格式，新增屋頂回歸測試並重新檢視日夜截圖。

## 邊界與未解風險

- CUA 與 Chrome DevTools 均無法連上使用者瀏覽器；沒有宣稱已在既有 Chrome 完成人工驗收。
- 原型模型比概念圖簡化，未加入牛車、聊天動畫及音效。
- 地圖有界，建造後重算路網可能讓移動者略為重新定位。
- 行動裝置只驗證窄螢幕版面，尚未實機觸控驗收。
- 尚未部署到公開遊戲網址；本機由 Vite 提供預覽。

## 下一步

取得使用者對可玩原型的回饋後，下一個獨立里程碑可著重街坊院落細節、居民互動與音景。保留現有測試與圖片證據，不把概念圖當成成品截圖。
