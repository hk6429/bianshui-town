# 第一版可玩原型交接

## 已完成

四張開發前概念圖（實際內容使用繁體中文）、Three.js 場景、共享街坊、道路圖、居民日程與尋路、施工、檢視卡、日夜光線、探索相機、示範小鎮、自動存檔。

## 驗證證據

- `npm test`：8 / 8 通過。
- `npm run build`：通過；主 JS 534.80 kB、gzip 138.90 kB，Vite 提醒單一檔案超過 500 kB。
- `tests/browser-check.mjs`：獨立 Chromium 自動化通過。三格拖曳、探索不建造、入住人口、檢視、確認重設、居民移動、返家、夜景、390px 工具列皆有檢查。
- `evidence/browser-check.json`：0 執行錯誤，4 / 4 概念圖載入；範例場景 386 次繪製、69,796 三角形。
- `evidence/01-empty.png` 至 `06-mobile.png`：實際測試瀏覽器截圖。
- 模型屋頂曾因 indexed / non-indexed 幾何與 UV 屬性不一致而合併失敗；已統一格式，新增屋頂回歸測試並重新檢視日夜截圖。

## 邊界與未解風險

- CUA 與 Chrome DevTools 均無法連上使用者瀏覽器；沒有宣稱已在既有 Chrome 完成人工驗收。
- 原型模型比概念圖簡化，未加入牛車、聊天動畫及音效。
- 地圖有界，建造後重算路網可能讓移動者略為重新定位。
- 行動裝置只驗證窄螢幕版面，尚未實機觸控驗收。
- 尚未部署到公開遊戲網址；本機由 Vite 提供預覽。

## 下一步

取得使用者對可玩原型的回饋後，下一個獨立里程碑可著重街坊院落細節、居民互動與音景。保留現有測試與圖片證據，不把概念圖當成成品截圖。
